# Asterra · 星野漫记

> 让生活中的每一个想法，都有安放之处。
>
> A personal open-source Android app, built for everyday life.

## ✨ 项目简介

**Asterra（星野漫记）** 是一个生活助手、一个实用工具箱，也可能是记录日常灵感和探索新技术的地方。

想到什么，就尝试实现什么。

## 🛠️ 技术栈

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Minimum SDK:** Android 8.0 (API 26)
- **Build System:** Gradle Kotlin DSL
- **IDE:** Android Studio

## 📦 本地构建

1. 克隆仓库：

   ```bash
   git clone https://github.com/vinova-vito/asterra.git
   ```

2. 使用 Android Studio 打开项目。
3. 等待 Gradle Sync 完成。
4. 连接 Android 设备或启动模拟器。
5. 点击 **Run** 运行项目。
